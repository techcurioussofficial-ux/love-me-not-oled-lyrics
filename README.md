# Love Me Not – OLED Lyrics Animation

A DIY Arduino OLED project featuring animated lyrics and custom visual effects.

## Features

* Animated lyrics display
* Custom animation frames
* OLED-based visual effects
* Arduino-powered DIY project

## Components Required

* Arduino Uno (or compatible board)
* 1.3-inch OLED Display (128×64)
* Jumper wires
* Breadboard (optional)

## Project Files

* `loveMeNotOledLyrics.ino` – Main Arduino sketch
* `animation_frames.h` – Animation frame definitions

## How to Use

1. Download or clone this repository.
2. Open `loveMeNotOledLyrics.ino` in Arduino IDE.
3. Ensure `animation_frames.h` is in the same folder.
4. Install the required OLED libraries if prompted by the IDE.
5. Select your board and COM port.
6. Upload the sketch.
